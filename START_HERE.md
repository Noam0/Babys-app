## 🎨 Quick Customizations

### Change Baby's Photo
1. Open `src/components/Header.jsx`
2. Find the `<img src=...` line
3. Replace URL with Gefen's photo
4. Save and refresh!

### Change Birthdate

2. Update the `BIRTHDATE` line
3. Age updates automatically!

## 📱 Install as PWA on iPhone

### Steps:
1. Open Safari on your iPhone
2. Navigate to: http://YOUR_COMPUTER_IP:5180
   - Find IP: `ipconfig` on Windows, `ifconfig` on Mac
3. Tap the **Share** button (square with arrow)
4. Scroll and tap **"Add to Home Screen"**
5. Tap **"Add"**
6. App appears on home screen! 🎉

### Make it sync:
- Set up Supabase (SETUP_GUIDE.md)
- Install on both phones
- Events sync automatically!

## 🆘 Need Help?

### App Not Working?
- Check console for errors (F12 in browser)
- Make sure dev server is running
- Try `npm install` again

### Can't Access on Phone?
- Make sure both devices on same WiFi
- Check firewall settings
- Try turning off VPN

### Real-Time Not Working?
- Supabase must be configured
- Check .env file has correct values
- Enable replication in Supabase

### Something Else?
- Check README.md for detailed info
- Check the relevant guide file
- Google the error message
