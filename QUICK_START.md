# ⚡ Quick Start - Get Running in 5 Minutes

## Option 1: Run Locally (No Setup)

The app will work immediately with local storage - perfect for testing!

```bash
npm run dev
```

Open http://localhost:5180 in your browser. Events will only be stored locally.

## Option 2: Full Setup with Real-Time Sync

To enable real-time sync between devices, follow the **SETUP_GUIDE.md** (takes ~10 minutes).

---

## What You Get Right Away

✅ All tracking features work  
✅ Beautiful Hebrew UI  
✅ Age calculator  
✅ Weight tracking  
✅ Event history

❌ Real-time sync between devices (requires Supabase)
